<h1>Introduction</h1>

A personal portfolio website developed using Python and Django.

Various sections of the website can be dynamically managed and updated through the admin panel, including:

- Personal Information
- Work Experience
- Skills
- Work Features
- Client Testimonials
- Blog

<h2>Front End</h2>

Frontend development was not the primary focus of this project. The website uses a pre-built template purchased from the Rightelchin (Rastchin) marketplace.

<h2>Running the Project</h2>

1. Clone the repository:

   ```bash
   git clone https://github.com/AmiraliTanabian/Django_PersonalSite
   ```

2. Navigate to the project directory.

3. Run Docker Compose:

   ```bash
   docker compose up --build
   ```
4- Go to localhost:8000
